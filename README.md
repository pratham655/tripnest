# TripNest

TripNest is an AI-powered travel planning web application that helps users discover destinations, create personalized travel plans, estimate budgets, track weather conditions, and maintain a bucket list of dream destinations.

## Live Demo

🌐 Live Application: https://tripnest-684145866030.asia-southeast1.run.app/

📂 GitHub Repository: https://github.com/pratham655/tripnest

---

## Features

### Destination Discovery
- Search and explore travel destinations
- View destination information
- Browse popular and recommended places
- Discover attractions and activities

### AI Trip Planner
- Generate personalized travel itineraries
- Customize plans based on:
  - Budget
  - Duration
  - Interests
  - Destination
- Day-wise trip planning

### Budget Estimator
- Estimate overall trip expenses
- Cost breakdown for:
  - Accommodation
  - Transportation
  - Food
  - Activities
- Budget-friendly travel planning

### Weather Information
- Current weather conditions
- Forecast information
- Travel recommendations based on weather

### Interactive Maps
- Explore destinations on maps
- Locate attractions and points of interest
- Route visualization

### Bucket List
- Save favorite destinations
- Manage future travel plans
- Mark visited locations

## Installation

### Clone the repository

```bash
git clone https://github.com/pratham655/tripnest.git
```

### Navigate to the project folder

```bash
cd tripnest
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add the required API keys.

```env
API_KEY=your_api_key_here
```

### Start the development server

```bash
npm run dev
```

### Open in browser

```text
http://localhost:3000
```
