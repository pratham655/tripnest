# 🌍 TripNest

TripNest is an AI-powered travel planning application that helps users discover destinations, generate personalized itineraries, estimate travel budgets, check weather forecasts, explore locations on interactive maps, and save dream destinations to a bucket list.

## 🚀 Live Demo

https://tripnest-684145866030.asia-southeast1.run.app/

## 📂 GitHub Repository

https://github.com/pratham655/tripnest

## ✨ Features

- 🌎 Explore travel destinations
- 🤖 AI-powered itinerary generation
- 💰 Trip budget estimation
- 🌤️ Weather forecasts
- 🗺️ Interactive maps
- ⭐ Personal bucket list
- 📱 Responsive design
